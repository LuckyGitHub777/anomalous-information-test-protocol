# Generalized Claim Testing

AITP's core implementation is optimized for blinded hidden-information tests. The same evidence discipline can be applied more broadly without pretending every problem is a hidden-target experiment.

A useful generalized chain is:

**Claim → Observable → Null Model → Confounders → Minimum Distinguishing Test → Measurement → Replication → Qualification → Decision**

## Why this matters

A surprising signal is not automatically a new phenomenon. The first engineering task is to specify what was observed, what ordinary mechanisms can produce a similar signal, what measurement would distinguish the hypotheses, and what replication would be sufficient to change a decision.

## Claim Test Card

Use [`templates/claim_test_card.md`](../templates/claim_test_card.md) for claims involving sensors, materials, forecasting, model behavior, or other domains where the core AITP target/ranking machinery is not the right experimental form.

## Boundary

This document generalizes **method discipline**, not ontology. It does not make extraordinary physical, spiritual, anomalous, or nonhuman claims true by association with AITP.
