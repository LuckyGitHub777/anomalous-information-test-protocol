# Product Experience

## North star

AITP should feel like a **modern scientific observatory for evidence under uncertainty**.

A first-time visitor should understand:

> AITP tests whether information was available before the answer was known, while preserving the order and integrity of the evidence.

The experience never requires belief in an extraordinary explanation.

## Value promise

A completed AITP workflow should leave the user with four concrete things: an evidence packet, an audit verdict, an analysis-ready record, and a clear interpretation boundary. The Prediction Ledger adds a fifth repeat-use asset: an immutable claim plus append-only adjudication.

The public experience should make that value understandable before asking anyone to install software. The Laboratory should make the same value tangible without exposing the operator to JSON or cryptographic machinery unless they ask for it.

## Complete journey

**Discover → Understand → Experience → Trust → Inspect → Run locally → Test → Audit → Adjudicate → Replicate → Return**

### Public web

Static, synthetic, educational. No real study data; no demo telemetry.

### Local Laboratory

Private dry-run workspace plus local Prediction Ledger freeze/adjudication. Formal anchored studies remain the expert/core workflow until the guided formal UX has independent evidence behind it.

### GitHub

The proof layer: code, protocol, schemas, tests, threat model, claims boundary, rendered-UAT workflow, and reproducible release evidence.

## Experience doctrine

1. Evidence before explanation.
2. Simple truth first; technical detail on demand.
3. Interface state must match protocol state.
4. Luxury means removing friction, not rigor.
5. No spectacle or gamified extraordinary-success language.
6. Failures remain evidence and are visibly excluded from inference.
7. Privacy/security statements describe only implemented protections.
8. Every green check means exactly one named proposition.

## Repeat-use value

**Create → Run → Review → Learn → Refine → Repeat**

The Evidence Cabinet makes trial state resumable. The Prediction Ledger preserves the original claim, then appends adjudication rather than mutating history.
