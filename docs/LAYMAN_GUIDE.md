# AITP in Plain English

## What is this?

AITP is a **digital laboratory kit for testing “How could you have known that?”**

If a person, model, or method claims to know something hidden or future-facing, AITP helps run a fair test without requiring anyone to believe or dismiss the explanation first.

## The simple idea

1. Secretly choose an answer.
2. Lock proof of that answer before the participant responds.
3. For a formal study, preserve separate evidence that the commitment was anchored before the response.
4. Record and seal the participant response.
5. Only then show candidate answers to a blinded judge.
6. Seal the judge's ranking.
7. Reveal the real answer.
8. Audit the evidence chain.
9. Use statistics before making an explanation.

## What does it not prove?

AITP does not establish psychic ability, telepathy, nonhuman intelligence, extraterrestrial communication, or any other mechanism merely because a result is unusual.

It is the **instrument**, not the conclusion.

## Public web experience

The public static site teaches the sequence with synthetic data. It is educational and does not create research-grade chronology.

## Local Laboratory

Run:

```bash
python run_lab.py
```

or double-click `AITP_LAB.cmd` on Windows.

The v1.1 guided Laboratory supports honest **dry runs**:

- create a synthetic trial;
- seal a response;
- rank candidates;
- seal the judgment;
- reveal and audit;
- review local evidence.

Formal anchored studies remain an expert/core workflow because the software should not pretend to verify an external witness when it cannot.

## Prediction Ledger

Freeze the exact words and success/failure criteria before reality answers. Later, append an adjudication without changing the frozen prediction.

The public synthetic record and local Laboratory use the same canonical prediction-content fingerprint.
