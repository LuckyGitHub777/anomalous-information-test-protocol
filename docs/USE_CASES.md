# Use Cases

AITP is useful when the key problem is **prospective evidence integrity**.

## Core fit
- blinded hidden-target experiments;
- condition-vs-baseline information tests;
- preregistered prediction scoring;
- replication of anomalous-information claims.

## Adaptable fit
- expert-intuition calibration;
- AI/model forecasting with frozen versions and outputs;
- technology or event predictions;
- anomaly qualification where confounders and null models must be bounded;
- reproducibility exercises.

## Poor fit
AITP is not a substitute for domain-specific physics, medicine, engineering, legal analysis, or safety practice. Use the correct domain methods and use AITP-style provenance/chronology controls only where they add value.
